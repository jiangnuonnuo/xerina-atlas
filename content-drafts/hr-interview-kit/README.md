## 二、HR 面的底层逻辑（先看懂再背）

HR 面只考三件事，技术问题只是载体：

1. **真实性** —— 简历上写的是不是你干的？（对应风险点 ①③④）
2. **稳定性** —— 你会不会来、来了会不会跑、能不能干长？（对应风险点 ②⑥）
3. **性价比** —— 你的能力是否值这个价，好不好带？（对应风险点 ④⑤⑦）

**答题总原则**：
- 每个回答都往这三个柱子上靠，别自说自话炫技；
- 用 **STAR + 数字 + 反思** 三段式，结尾一定要有"我学到了什么 / 下次怎么改"；
- **不撒谎，但可以选择叙事重心**。没做过的事绝不说做过；做过但做得糙的，讲清楚你当时为什么那么决策；
- 遇到不知道的，直接说"这个我没经历过，但我会这样处理"，比硬编安全十倍。

## 四、使用方法

1. **先填坑再背诵**：`04` 篇里标 🚨 的地方是**只有你自己知道的实情**，我无法代填，必须你本人补真话，否则背了也是背一个假答案，一问就穿；
2. 每篇按"**问题 → 遮住回答自己出声答 → 对照改**"；
3. 回答里的 `【…】` 是可替换的变量（公司名、岗位名），实际面试前替换掉；
4. HR 面**不需要背到一字不差**，但结构、数字、结尾反思这三样必须固定；
5. 之后你随时可以把 HR 的原话丢给 AI，让它继续以"面试者"身份接招。

## 五、与面试官提示词的关系

`interviewer-role-prompt.md` 是**技术面**的面试官角色模板（项目深挖 / 八股）。HR 面建议另起一套参数：

```text
你是【{公司}】的 HR 面试官，正在面 2027 届 Java 后端 / AI 应用方向候选人。
面试模式：综合素质面（非技术深挖）。
范围：真实性核验 → 稳定性判断 → 软素质 → 压力测试 → 反问。
风格：真实面试风（不即时点评）。
诚实度口径：简历内容按"本人主导、数据有据"处理，但请重点攻击简历中的时间空档与定位不一致。
结束输出：按 真实性 / 稳定性 / 软素质 / 沟通表达 / 性价比 五维评分 + 最致命风险点。
```
