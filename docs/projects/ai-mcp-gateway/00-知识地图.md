# 项目知识地图

这份地图用于说明每篇文章的边界，而不是重复项目总览。

| 文章 | 读者获得的结论 | 主要证据 | 依赖 |
| --- | --- | --- | --- |
| 项目背景与定位 | 这个系统为什么不是普通代理 | 网关入口、管理能力、验收资料 | 无 |
| DDD 分层与系统架构 | 每层负责什么，依赖为何朝向 Domain | Maven 模块、Domain Port、Repository | 背景 |
| 领域模型与业务边界 | Gateway、Tool、Protocol、Package、Session 如何区分 | Domain Entity、VO、Service | 架构 |
| HTTP/OpenAPI 转 MCP | 外部接口怎样获得 MCP 参数和结果契约 | ProtocolAnalysis、ProtocolExecuteService | 领域模型 |
| MySQL、SQL 与 Redis 转 MCP | 数据源如何变成受控工具 | DataSourceSafetyChain、Runtime Port | 领域模型 |
| MCP 会话与传输 | 长连接、JSON-RPC、恢复和租约如何协作 | SessionManagementService、Streamable Service | 架构 |
| 能力包发布与缓存 | 为什么草稿不能直接被客户端看到 | Publish Rule、Runtime Cache Repository | 领域模型 |
| 工具执行与 LLM | 模型如何通过策略调用不同下游 | ToolInvocationService、Strategy Factory | 协议、数据源 |
| 认证权限与隔离 | 网关、能力包、会话、令牌、数据源如何隔离 | License、RateLimit、AES/HMAC | 会话、能力包 |
| 一致性、多实例与部署 | MySQL、Redis、本地会话各自是什么事实 | Redis Sync、Compose、配置 | 发布、会话 |
| 测试与验收 | 如何证明链路可用，哪些问题属于环境限制 | 测试类、MVP 验收报告 | 全部 |
