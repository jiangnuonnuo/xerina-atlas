# Q1.1

## 题干
`synchronized` 是 Java 并发编程中最基础的关键字。请谈谈：**`synchronized` 关键字有哪些常见的加锁方式？** 分别加在实例方法、静态方法、代码块上时，锁的对象分别是什么？各有什么实际影响？

## 开卷
询问synchronized常见加锁方式，以及加在实例方法、静态方法、代码块时的锁对象和实际影响
- synchronized常见加锁方式分为三类：修饰实例方法、修饰静态方法、修饰同步代码块
- 加在实例方法上时，锁对象为当前调用该方法的实例（this），仅当前实例的该方法会被互斥执行，不同实例间互不干扰
- 加在静态方法上时，锁对象为当前类的Class对象，所有实例的该静态方法共享同一把锁，全局互斥
- 加在同步代码块上时，锁对象为synchronized括号内显式指定的对象，支持自定义锁对象，可灵活控制锁粒度
- 实例方法锁适合操作实例级共享资源的场景，静态方法锁适合操作类级静态共享资源的场景，代码块锁可通过缩小同步范围降低锁竞争、提升并发性能
