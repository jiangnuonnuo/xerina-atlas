# Q3.1

## 题干
在并发编程中，**线程池**是管理线程的核心工具。请说说：**Java 中创建线程池最常用的类是哪一个？** 它有哪些核心参数？如果不合理设置参数，可能会带来什么问题？

## 开卷
Java线程池最常用类及其核心参数与不合理设置的后果
- 核心类为ThreadPoolExecutor（通常通过Executors工厂类或直接new创建）
- 七大核心参数：corePoolSize（核心线程数）、maximumPoolSize（最大线程数）、keepAliveTime（空闲存活时间）、unit（时间单位）、workQueue（任务队列）、threadFactory（线程工厂）、handler（拒绝策略）
- 无界队列（如LinkedBlockingQueue）配合不当可能导致OOM（内存溢出）
- corePoolSize设置过大会导致频繁线程上下文切换，浪费CPU资源
- 队列容量不足或拒绝策略配置不当可能导致任务被丢弃或系统响应延迟
- keepAliveTime设置不当可能导致线程资源浪费或频繁创建销毁开销
