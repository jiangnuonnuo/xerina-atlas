## 题干
在 Java 并发编程中，**`ThreadLocal`** 是一种非常常用的工具。请说说：**`ThreadLocal` 的基本作用是什么？它通常在什么业务场景下会被用到？**

## 开卷
说明ThreadLocal的基本作用及常用业务场景
- ThreadLocal可为每个线程提供独立的变量副本，实现线程隔离，避免多线程共享变量导致的线程安全问题，无需加锁同步
- 可用于数据库连接、会话（Session）等资源的线程级复用，减少重复创建销毁的开销，提升性能
- 可用于Web请求上下文的存储，比如用户身份、请求链路ID等，在多层级方法调用中无需透传参数
- 可用于封装线程不安全的工具类（如SimpleDateFormat），为每个线程提供独立实例，避免并发异常
- 可用于框架内部状态管理，比如Spring的RequestContextHolder存储请求相关的上下文信息
