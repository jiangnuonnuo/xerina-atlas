# 本轮总结

主题：Java 并发编程
难度：初级

## 表现与建议

本轮Java并发初级考察中，候选人对线程创建方式的四种常见方案掌握较好，能清晰阐述各自特点与适用场景，但整体基础覆盖存在明显缺口，核心薄弱点集中在两方面：一是高频核心基础概念完全未掌握，synchronized的加锁分类、锁对象对应关系与实际影响，volatile的特性边界、与synchronized的核心差异，ThreadLocal的线程隔离原理与典型业务应用均未作答，属于并发基础框架的缺失；二是已有作答内容细节完整度不足，遗漏了线程启动时start()与run()方法的核心区别、Callable接口配合FutureTask获取异步结果的具体用法，以及不同线程创建方式在资源复用性上的本质差异。
下轮复习需要优先补全并发核心基础：系统梳理synchronized三类加锁方式的锁对象、互斥范围与适用场景，理解volatile可见性实现原理、无法保证线程安全的核心原因，以及和synchronized在可见性、原子性上的具体区别，掌握ThreadLocal的线程隔离逻辑与数据库连接复用、请求上下文传递、线程不安全工具类封装等常见业务场景；其次补充已有知识点的细节盲区，明确不同线程创建方式在资源开销上的差异，掌握Callable异步任务的结果获取与取消操作；最后针对待考察的线程池模块，重点记忆核心参数的含义与不合理配置的影响，结合业务场景练习不同并发需求下的方案选型，把零散知识点和实际应用场景关联起来。
