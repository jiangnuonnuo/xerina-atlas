# Q1.1

## 题干
**本题：Spring Boot 的自动配置主要是通过什么机制或核心注解来完成的？** 也就是说，当你引入 `spring-boot-starter-web` 后，Spring Boot 是怎么自动帮你配好 Tomcat 和 Spring MVC 的？

## 开卷
Spring Boot自动配置的核心机制与核心注解，以及引入spring-boot-starter-web后自动配置Tomcat和Spring MVC的原理
- 核心入口注解为@SpringBootApplication，其组合了@EnableAutoConfiguration注解用于开启自动配置功能
- 自动配置依赖spring-boot-autoconfigure模块，通过META-INF/spring.factories文件注册所有自动配置类，启动时会被自动加载
- 自动配置基于条件注解实现，常用@ConditionalOnClass判断类路径是否存在指定类、@ConditionalOnMissingBean判断容器是否缺少对应Bean，仅满足条件时才会执行配置逻辑
- 引入spring-boot-starter-web后，传递依赖引入了Tomcat、spring-webmvc等相关类，满足条件后自动加载WebMvcAutoConfiguration、TomcatServletWebServerFactory等自动配置类
- 自动配置类会自动注册DispatcherServlet、嵌入式Tomcat容器等核心Bean，完成Spring MVC和Tomcat的默认配置，用户自定义的Bean可覆盖自动配置的内容

## 作答
核心入口注解为@SpringBootApplication，其组合了@EnableAutoConfiguration注解用于开启自动配置功能
自动配置依赖spring-boot-autoconfigure模块，通过META-INF/spring.factories文件注册所有自动配置类，启动时会被自动加载
自动配置基于条件注解实现，常用@ConditionalOnClass判断类路径是否存在指定类、@ConditionalOnMissingBean判断容器是否缺少对应Bean，仅满足条件时才会执行配置逻辑
引入spring-boot-starter-web后，传递依赖引入了Tomcat、spring-webmvc等相关类，满足条件后自动加载WebMvcAutoConfiguration

## 对照
已覆盖：核心入口注解@SpringBootApplication组合@EnableAutoConfiguration用于开启自动配置；自动配置依赖spring-boot-autoconfigure模块，通过META-INF/spring.factories文件注册自动配置类，启动时自动加载；自动配置基于@ConditionalOnClass、@ConditionalOnMissingBean等条件注解实现按需配置；引入spring-boot-starter-web后传递依赖引入Tomcat、spring-webmvc等相关类，满足条件后加载WebMvcAutoConfiguration等自动配置类
未覆盖：未提及TomcatServletWebServerFactory等Tomcat相关自动配置类，以及自动注册嵌入式Tomcat容器、DispatcherServlet等核心Bean的配置逻辑；未提及用户自定义Bean可覆盖自动配置内容的特性
候选人准确覆盖了Spring Boot自动配置的核心基础机制，包括核心注解组合、模块与注册机制、条件注解原理，以及引入spring-boot-starter-web触发自动配置的基础逻辑，但遗漏了Tomcat及Spring MVC核心组件的具体自动配置细节，以及自动配置的可覆盖边界特性，整体掌握程度较好但存在细节缺漏
