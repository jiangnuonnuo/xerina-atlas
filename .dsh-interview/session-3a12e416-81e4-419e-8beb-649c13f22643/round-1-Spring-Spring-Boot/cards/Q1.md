# Q1

## 题干
**本题：Spring Boot 的核心特性有哪些？请简要说明你最熟悉的 3 点。**

## 开卷
Spring Boot 核心特性列举及任意3点的简要说明
- 自动配置（Auto-configuration）：根据Classpath中的jar依赖自动配置Bean，减少手动@Configuration类编写
- 起步依赖（Starters）：提供一站式依赖管理（如spring-boot-starter-web），简化Maven/Gradle配置
- 嵌入式Web服务器：内嵌Tomcat/Jetty/Undertow，无需部署WAR包，可直接java -jar运行
- 生产就绪（Production-ready）：Actuator提供健康检查、指标监控、审计等生产级功能
- 外部化配置：支持application.properties/yml及多种格式，支持多环境Profile配置
